配点 : $366$ 点

### 問題文

高橋君の学校には $N$ 人の生徒がおり、生徒には $1$ から $N$ までの番号が付けられています。生徒同士の友人関係が $M$ 個与えられ、$i$ 番目の友人関係は生徒 $u_i$ と生徒 $v_i$ が互いに友人であることを表します（友人関係は双方向です）。なお、同じ友人関係が複数回与えられることや、ある生徒が自分自身と友人であるような関係は存在しません。

はじめに、$K$ 人の生徒 $C_1, C_2, \ldots, C_K$ だけがある噂を知っている状態です。この初期状態から、噂は次のルールに従って日ごとに広がります。

> **判定：** 各日の開始時点で、まだ噂を知らない生徒それぞれについて、その生徒の友人のうち噂を知っている人数を数えます。この人数が $T$ 人以上であれば、その生徒はその日の終わりに新たに噂を知ります。

>

> **同時更新：** その日に新たに噂を知る生徒が複数いる場合、それらは全員同時にその日の終わりに噂を知ります。ある生徒がその日の終わりに新たに噂を知ったとしても、それは同じ日の他の生徒の判定には影響しません。

この過程を、新たに噂を知る生徒がいなくなるまで毎日繰り返します。

最終的に噂を知っている生徒の人数を求めてください。

### 制約

  * $1 \leq N \leq 2 \times 10^5$
  * $0 \leq M \leq 2 \times 10^5$
  * $1 \leq K \leq N$
  * $1 \leq T \leq N$
  * $1 \leq C_i \leq N$ $(1 \leq i \leq K)$
  * $C_i$ はすべて異なる
  * $1 \leq u_i < v_i \leq N$ $(1 \leq i \leq M)$
  * $(u_i, v_i)$ の組はすべて異なる
  * 入力はすべて整数



* * *

### 入力
    
    
    N M K T
    C_1 C_2 \ldots C_K
    u_1 v_1
    u_2 v_2
    \vdots
    u_M v_M

  * $1$ 行目には、生徒の数 $N$、友人関係の数 $M$、初めに噂を知っている生徒の数 $K$、噂が伝わるために必要な友人の人数の閾値 $T$ が、スペース区切りで与えられる。
  * $2$ 行目には、初めに噂を知っている生徒の番号 $C_1, C_2, \ldots, C_K$ がスペース区切りで与えられる。
  * $3$ 行目から $M + 2$ 行目には、友人関係が $M$ 行で与えられる。
  * $2 + i$ 行目 $(1 \leq i \leq M)$ には、$i$ 番目の友人関係における生徒の番号 $u_i$ と $v_i$ がスペース区切りで与えられる。



### 出力

噂の拡散が収束した後に噂を知っている生徒の人数を $1$ 行で出力せよ。
