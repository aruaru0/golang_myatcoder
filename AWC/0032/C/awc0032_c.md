配点 : $366$ 点

### 問題文

高橋君は登山が趣味で、各地の展望台から見える山々の情報をまとめています。

ある山岳地帯には $N$ 座の山があり、 $i$ 番目の山は標高 $Y_i$ メートル、その山の美しさの評価値は $P_i$ です。

高橋君は $Q$ 回の調査を行います。各調査では、基準となる標高 $L_j$ が決められており、標高が $L_j$ 以上であるすべての山の美しさの評価値の合計を求めたいと考えています。

各調査に対する答えを求めてください。

### 制約

  * $1 \leq N \leq 2 \times 10^5$
  * $1 \leq Q \leq 2 \times 10^5$
  * $1 \leq Y_i \leq 10^9$
  * $1 \leq P_i \leq 10^9$
  * $1 \leq L_j \leq 10^9$
  * 入力はすべて整数である



* * *

### 入力
    
    
    N Q
    Y_1 P_1
    Y_2 P_2
    :
    Y_N P_N
    L_1
    L_2
    :
    L_Q

  * $1$ 行目には、山の数を表す $N$ 、調査の回数を表す $Q$ が、スペース区切りで与えられる。
  * $2$ 行目から $N + 1$ 行目では、各山の情報が与えられる。
  * $1 + i$ 行目では、 $i$ 番目の山の標高 $Y_i$ と美しさの評価値 $P_i$ が、スペース区切りで与えられる。
  * $N + 2$ 行目から $N + 1 + Q$ 行目では、各調査の基準標高が与えられる。
  * $N + 1 + j$ 行目では、 $j$ 番目の調査の基準標高 $L_j$ が与えられる。



### 出力

$Q$ 行にわたって、各調査の答えを出力せよ。 $j$ 行目には、 $j$ 番目の調査に対して、標高が $L_j$ 以上であるすべての山の美しさの評価値の合計を出力せよ。該当する山が存在しない場合は $0$ を出力せよ。
