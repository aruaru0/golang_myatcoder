配点 : $300$ 点

### 問題文

> コワスギ銀行の裏庭では、幽霊がカボチャを育てています。あなたはカボチャたちに銀行口座を開設してあげることにしました。

カボチャ用銀行口座には、開設時に名前と ID を $1$ 個ずつ割り当てます。ID の値を選ぶときは、まだ ID として使われていない正の整数のうち最小のものを採用します。

はじめ、カボチャ用銀行口座はひとつも開設されていません。以下の出来事が $Q$ 回起きるので、順に処理してください。

  * カボチャがやってきて、名前 $s$ を名乗る。
    * 名前 $s$ が割り当てられた口座が存在する場合、その ID を出力する。
    * 名前 $s$ が割り当てられた口座が存在しない場合、名前 $s$ の口座を新規に $1$ 個開設し、その ID を出力する。



### 制約

  * $Q$ は $1$ 以上 $2 \times 10^5$ 以下の整数
  * 各出来事において、$s$ は英小文字からなる長さ $1$ 以上 $10$ 以下の文字列



* * *

### 入力

入力は以下の形式で標準入力から与えられる。
    
    
    Q
    \mathrm{query}_1
    \vdots
    \mathrm{query}_Q

$\mathrm{query}_i$ は $i$ 回目の出来事を表し、以下の形式で与えられる。
    
    
    s

### 出力

$Q$ 行出力せよ。$i$ 行目には、$i$ 回目の出来事で出力するべき値を出力せよ。

* * *

### 入力例 1
    
    
    8
    pumpkin
    hobak
    pompoen
    hobak
    pumpkin
    boga
    boga
    hobak

### 出力例 1
    
    
    1
    2
    3
    2
    1
    4
    4
    2

出来事は以下のように進みます。

  * $1$ 回目の出来事において、名前 `pumpkin`、ID $1$ の口座を新規に開設する。
  * $2$ 回目の出来事において、名前 `hobak`、ID $2$ の口座を新規に開設する。
  * $3$ 回目の出来事において、名前 `pompoen`、ID $3$ の口座を新規に開設する。
  * $4$ 回目の出来事において、名前 `hobak` の口座は既にあり、その ID は $2$ である。
  * $5$ 回目の出来事において、名前 `pumpkin` の口座は既にあり、その ID は $1$ である。
  * $6$ 回目の出来事において、名前 `boga`、ID $4$ の口座を新規に開設する。
  * $7$ 回目の出来事において、名前 `boga` の口座は既にあり、その ID は $4$ である。
  * $8$ 回目の出来事において、名前 `hobak` の口座は既にあり、その ID は $2$ である。
