配点 : $300$ 点

### 問題文

数直線上の座標 $1, 2, \ldots, N$ に $1$ 個ずつ点があり、座標 $i$ にある点を点 $i$ と呼びます。

各点には色がついており、点 $i$ の色は $C_i$ です。ただし、$C_1, C_2, \ldots, C_N$ に現れる値は $2$ 種類以上あります。

各 $i = 1, 2, \ldots, N$ について、点 $i$ と異なる色の点のうち、点 $i$ からの距離が最も短いものまでの距離を求めてください。

### 制約

  * $2 \leq N \leq 3 \times 10^5$
  * $1 \leq C_i \leq N$
  * $C_1, C_2, \ldots, C_N$ に現れる値は $2$ 種類以上
  * 入力される値はすべて整数



* * *

### 入力

入力は以下の形式で標準入力から与えられる。
    
    
    N
    C_1 C_2 \ldots C_N

### 出力

$i = 1, 2, \ldots, N$ に対する答えをこの順に空白区切りで出力せよ。

* * *

### 入力例 1
    
    
    6
    1 1 2 3 3 3

### 出力例 1
    
    
    2 1 1 1 2 3

点 $1$ と異なる色の点のうち、点 $1$ から最も近い点は点 $3$ であり、点 $1$ からの距離は $2$ です。

点 $2$ と異なる色の点のうち、点 $2$ から最も近い点は点 $3$ であり、点 $2$ からの距離は $1$ です。

点 $3$ と異なる色の点のうち、点 $3$ から最も近い点は点 $2$ と点 $4$ であり、点 $3$ からの距離は $1$ です。

点 $4$ と異なる色の点のうち、点 $4$ から最も近い点は点 $3$ であり、点 $4$ からの距離は $1$ です。

点 $5$ と異なる色の点のうち、点 $5$ から最も近い点は点 $3$ であり、点 $5$ からの距離は $2$ です。

点 $6$ と異なる色の点のうち、点 $6$ から最も近い点は点 $3$ であり、点 $6$ からの距離は $3$ です。

したがって、$2, 1, 1, 1, 2, 3$ をこの順に空白区切りで出力します。

* * *

### 入力例 2
    
    
    7

### 出力例 2
    
    
    1 1 1 2 1 1 2
